一条指令后输入预想的密码进行测试

`mysql -h 127.0.0.1 -P 3306 -u root -p -e "SELECT 1;"`

- mysql 是MySQL命令行客户端
- -h 127.0.0.1 是主机地址这里可以按实际地址切换
- -P 3306 默认端口，大写P，小写-p是密码
- -u root 用户名 实际应该是root@主机的组合
- -p 这里是密码，后续单独填写 这里是交互式提示输入；密码不出现在命令行
- -e "SELECT 1;" 执行一条SQL后退出 非交互模式，适合脚本；成功退出码 0，失败非 0

如果把密码直接写成 `-proot123`，密码会出现在 shell 历史、`ps` 输出里，不安全，所以推荐单独 `-p`
